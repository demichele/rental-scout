Obtener token de Mercado Libre

Esto es el redirect URI del flujo Authorization Code. Mercado Libre te devuelve acá un code y el server lo canjea por APP_USR-....

Usá una app de developers.mercadolibre.com.ar (no Mercado Pago: ese OAuth no sirve para buscar avisos).

En la app, Redirect URI tiene que ser exactamente:

https://ESTE-DOMINIO/api/callback

Sin slash al final. El mismo valor va en la env MELI_REDIRECT_URI de Vercel.

Si ya autorizaste una vez, Mercado Libre no vuelve a pedir consentimiento: te redirige y emite un token con el mismo grant. Eso no es la autorización de la primera vez, y no cambia permisos (si el search da 403, un token nuevo igual va a dar 403).

Para autorizar de cero: revocá el grant (formulario abajo o Administrar permisos en la app) y después iniciá sesión de nuevo.

  1. Creá la app en Mercado Libre con esa URI.
  2. Cargá MELI_CLIENT_ID, MELI_CLIENT_SECRET y MELI_REDIRECT_URI en Vercel.
  3. Autorizá con tu usuario (cuenta principal, no colaborador).
  4. Copiá MELI_ACCESS_TOKEN al .env de rental-scout.
  5. Validá con python -m jobs.ping_meli (no con el scout).
Autorizar con Mercado Libre Cerrar sesión y autorizar

“Cerrar sesión y autorizar” te saca de Mercado Libre y después pide login. Si la app sigue autorizada, igual puede saltarse el consentimiento: usá el formulario.

Pegá el MELI_ACCESS_TOKEN actual (el que está en .env). Se manda a tu función de Vercel, no se guarda, y después arranca OAuth como la primera vez.
